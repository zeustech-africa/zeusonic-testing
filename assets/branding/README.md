Zeusonic Branding Assets

Directory: /assets/branding/

Files & naming conventions
- logo-full.svg — primary horizontal logo ("ZEUSONIC" + subtitle "by ZeusTech")
- logo-mark.svg — compact brand mark (for small spaces or favicon)
- logo-full.png — PNG fallback at 2x and 1x (logo-full@2x.png / logo-full.png)
- logo-mark.png — PNG fallback at 2x and 1x

Formats
- Prefer SVG for all logos and icons (scales crisply and easy to colorize)
- Provide PNG fallbacks (useful for older systems or places where raster is required)

Placement
- Header / Top-left: Use `logo-full` or `logo-mark` depending on responsive behaviour
- Keep sufficient clear space around logo equal to 1x the height of the main wordmark

Accessibility
- Include meaningful `alt` text on images: e.g., `alt="ZEUSONIC by ZeusTech"`

Versioning
- Store source SVGs in the directory and include a small COPYRIGHT or README note indicating ownership.
