UI Layout Blueprint (non-code)

Landing Page
- Hero section: full-bleed dark background, large headline, subheading, primary CTA (Upload / Get started). Background: subtle radial gradient and soft particle/waveform animation.
- Features: three-column band explaining upload, processing, and preview with small cards and icons.
- Social proof: small row of logos or testimonials.

Header
- Left: Zeusonic logo (logo-full or logo-mark depending on width)
- Right: Auth controls (Login / Sign-up), or demo key status for developer tools.

Main CTA Section
- Prominent heading and short subcopy
- Primary CTA is prominent (Accent 1), secondary CTA is ghost or outline.
- Small note about supported audio formats and size limits.

Dashboard Area (future)
- Left column: Upload panel (drag & drop, file selector)
- Main area: List of jobs, recent uploads, waveform preview for the selected track
- Right sidebar: metadata, export/share, controls for processing options

Notes
- Keep layout responsive: stacked on mobile, two/three-column on desktop
- Waveform visuals: use canvas or SVG, show progress and peaks with accent colors
